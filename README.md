# THREADLY — Wear Your Vibe

Plain HTML, CSS and JavaScript frontend version of the THREADLY clothing store project.

## Files
- `index.html` — Home page
- `products.html` — Product catalogue, search, filters and sorting
- `product.html` — Product detail page
- `cart.html` — Shopping cart
- `wishlist.html` — Wishlist
- `style.css` — Main styling and responsive design
- `script.js` — Product data and JavaScript functionality
- `images/` — Product and banner images

## How to run
Open `index.html` in a browser. No Node.js, React, PHP, MySQL or XAMPP is required for this frontend version.

## Features
Search, category/size/colour filters, price filter, sorting, product details, wishlist, cart, quantity controls, localStorage persistence, responsive layout, toast notifications and animations.

## Note
Checkout is a frontend demonstration only. Database/PHP integration can be added later.
